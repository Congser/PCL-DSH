# PCL DSH 改版 v1.3

> 把 **DeepSeek Harness (`dsh`)** 装进图形界面的启动器。
> 基于 [Plain Craft Launcher (PCL)](https://github.com/Meloong-Git/PCL) 的第三方独立二创，已剥离全部 Minecraft 功能。

---

## 本版新增

### 🗂 多版本并存

**以前装另一个 dsh 版本会就地覆盖** —— 旧版本直接没了，想"先试试新版、不满意再切回来"做不到。

现在每个版本装进自己的目录，随时切换：

```
runtime\
  dsh\                    ← 旧的单例目录（保留，老用户的运行时还在这里）
  versions\
    0.1.6-alpha.2\        ← 每个版本一个目录
    0.1.7-alpha.1\
```

- **装完不会自动切换** —— 装新版通常是为了试，不是立刻换掉在用的
- **切换时提醒插件兼容性**（统计各实例插件数并警告）
- **老用户不受影响**：旧的 `runtime\dsh\` 被当作普通槽位保留

### 📦 导出环境

「下载 → 镜像版本 → **导出环境…**」，四类内容任意勾选：

| 内容 | 默认 |
|---|---|
| 运行时 | ⬜ **不勾**（3.8 GB / 十几分钟；而插件+对话+配置才几百 MB） |
| 插件 | ✅ 勾 |
| 对话历史 | ✅ 勾 |
| 用户配置（含 API Key） | ⬜ **不勾**（导出是把数据给别人，默认值必须保守） |

勾上「用户配置」会**再确认一次**，并提供「**剔除密钥**」选项：
保留配置结构（接入方式、BaseUrl、模型名），密钥值留空 ——
别人导入后填自己的 Key 就能用。**「分享配置」不等于「分享密钥」**。

### 📥 导入环境

导出的包**能导回来了**（以前不含运行时的包会被直接拒收）。

导入时自动认包类型：
- **纯运行时包** → 装成一个运行时槽位
- **导出环境包** → 显示内容清单，让你选**导到哪个实例**，然后
  `runtime\` 装成新槽位、`home\` 的插件/对话/配置写进该实例

### 🔑 自定义网关不再强制 `sk-` 前缀

填自建网关 / 中转服务的 Key 时不再被「通常以 sk- 开头」拦下。
官方仍要求 `sk-`（能提前发现粘贴错误），自定义网关只做最小校验。

**配套安全改动**：日志脱敏原来**只认 `sk-` 开头的密钥**，
放开格式后自定义密钥会明文出现在日志里，而「AI 分析日志」会把日志发给 DeepSeek。
现在改成两层：**已知值精确替换**（从凭据文件读实际密钥，零漏网）+ **正则兜底**
（扩展 `sk_`/`key-`/`api-`/`token-` 变体与长 hex 串）。

### ✨ 检查更新明确告诉你该不该更新

版本号下面增加带底色的状态行：

| 情况 | 显示 |
|---|---|
| 有新版本 | 🟡 **发现新版本：0.1.7-alpha.1（预发布）—— 当前是 0.1.6-alpha.2，建议更新** |
| 已是最新 | 🟢 **已是最新版本（0.1.6-alpha.2）** |
| 还没装 | 🔵 **未安装 dsh —— 建议安装 x.x.x** |

用 semver 比较，`0.1.10 > 0.1.9` 判断正确。

### ⏱ 导出/导入实时进度

两行显示：阶段 + 百分比 / 具体在做什么（当前文件名）。带节流，界面不会卡。

## 修掉的缺陷

- **导出对话框用错**：弹的是「打开」而不是「保存」（用错 API）
- **保存路径被覆盖**：文件不落在你选的位置 —— 一段多余的"路径补全"把选择改掉了
- **「下载」菜单报错**：`Dir` 是 VB 内置函数，改名时漏改引用导致整页加载失败
- **导出卡死**：跟随符号链接统计体积撞上 pnpm 断链 → 异常风暴。已删除该逻辑，
  并给所有大目录遍历加日志节流

## 安装 / 升级

**从 v1.2 升级**：解压到**原位置**覆盖同名文件。数据目录不受影响，无需备份。

详见 [`docs/升级说明-v1.2到v1.3.md`](docs/升级说明-v1.2到v1.3.md)
