# 先看我 —— 三步用起来

## 1. 解压
把整个文件夹解压到任意位置（桌面、D 盘都行）。

> ⚠️ **别放在系统盘的临时目录里**（Windows 会清理 `%TEMP%`）。

## 2. 双击运行
双击 **`Plain Craft Launcher 2.exe`**

> ⚠️ 如果 Windows 弹出「已保护你的电脑」蓝框，点 **更多信息 → 仍要运行**。
> 这是 SmartScreen 对**没有购买数字签名证书**的程序的标准提示，不是病毒警告。

## 3. 点两下就能用
1. 进 **设置 → 启动**，如果看到「第一次使用」卡片，点 **带我做一遍**
   —— 它会自动把 Node / pnpm / dsh 都装好（**第一次约十几分钟**）
2. 进 **设置 → 启动 → 模型接入方式**，填入你的 **DeepSeek API Key**
3. 回 **启动** 页，点 **启动 DSH** —— 浏览器会自动打开界面

## ⚠️ 插件装不上 / 装很久？

**大概率是网络问题，不是软件坏了。**

国内直连 npm 官方源经常超时。如果看到进度条长时间停在
「网络不稳，正在重试……」或「下载速度较慢」，**换个镜像源通常一次就好**：

**下载 → 镜像版本 → 镜像源** → 选 **npmmirror（淘宝）** 或 **腾讯云镜像**

## 这个软件是什么

把 **DeepSeek Harness（dsh）** 装进图形界面的启动器。
不用碰命令行，打开就能拉起 dsh、管理多个实例、装插件、配密钥。

基于开源项目 **Plain Craft Launcher (PCL)** 的第三方独立二创（原作者：龙腾猫跃），
已剥离全部 Minecraft 功能。完整许可见 `LICENCE`。

> 💡 **每个实例的数据是完全独立的** —— 对话历史、API Key、插件各一套。
> 只有 dsh 运行时是共用的。详见 `使用说明.md`。

## 出问题怎么办

1. **顶部「日志」页** 有全部运行记录
2. 点 **AI 分析日志** —— 它会自动脱敏后交给 DeepSeek 分析，告诉你问题在哪
3. **设置 → 启动 → 维护与修复** → 点 **检查环境**，
   多数问题点 **一键修复** 就能解决
4. 实在不行，用 **快照** 回到之前正常的状态

反馈问题时，把日志页的内容一起发过来最快。
