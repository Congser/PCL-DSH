# PCL DSH 改版 —— 使用说明

这是一个把 **DeepSeek Harness（dsh）** 装进图形界面的启动器。
你不用碰命令行，打开它就能拉起 dsh、管理多个实例、装插件、配 API Key。

---

## 一、第一次用

1. 把整个文件夹解压到**任意位置**（桌面、D 盘都行）
2. 双击 **`Plain Craft Launcher 2.exe`**
3. 首次启动会弹出「运行环境」引导卡片 —— 点 **带我做一遍**
4. 等它装完（**第一次要下载约 480 个包，可能十几分钟**，进度条会走）
5. 进 **设置 → 启动**，在「模型接入方式」里填 **DeepSeek API Key**
6. 回 **启动** 页，点 **启动 DSH**，浏览器会自动打开 dsh 的界面

> 环境装在软件自己的目录里，**不会改你的系统 PATH、不写系统注册表**，
> 想删掉直接删整个文件夹即可。

---

## 二、常见操作

| 想干什么 | 去哪儿 |
|---|---|
| 再开一个独立的 dsh 环境 | 左栏 **我的实例** → 新建实例 |
| 配 API Key | 左栏 **密钥**（或设置里） |
| 装插件 | **下载 → 插件社区**（收录 4000+ 个插件） |
| 换 dsh 版本 / 换镜像源 | **下载 → 镜像版本** |
| **给当前状态留个还原点** | 顶部 **快照** |
| **让 AI 帮忙看日志** | 顶部 **日志** → **AI 分析日志** |
| **把散在各实例的对话集中起来** | **设置 → 启动 → 维护与修复 → 对话历史** |
| 体检 / 修复 / 换数据盘 | **设置 → 启动 → 维护与修复** |

### 关于多个实例
每个实例有**完全独立**的数据目录（插件、密钥、会话都分开），
但**共用同一份** dsh 运行时 —— 所以多开不会重复占用几个 G 的磁盘。

## 三、三个特色功能

### 快照（顶部菜单）
给实例拍一个还原点。出问题时可以整体回到那一刻。

- **快速快照**：只记配置与使用数据，**几 MB、一两秒**。
  恢复时按清单自动重装插件依赖（需要联网）
- **完整快照**：连插件依赖一起存，几百 MB、慢一些，但**完全离线可恢复**

恢复前会**自动给当前状态也拍一个快照**，点错了还能退回来。

> 什么时候用：装了个插件之后 dsh 起不来了、改了配置忘了改了什么、
> 想试试某个实验性插件又怕搞坏环境。

### AI 分析日志（顶部菜单 → 日志）
点一下，把日志（**已自动脱敏**：API Key、token、用户名路径都会被打码）
交给 DeepSeek 分析，直接告诉你「哪里出了问题、该怎么处理」。

优先用**官方 API**；官方没配或调用失败时，**自动回退**到你配的自定义网关。

> ⚠️ 它**只给建议，不会自动替你改任何东西**。需要执行时你自己确认。

### 从其他环境导入（设置 → 启动 → 维护与修复）
如果你另有一份手工搭好的 dsh 环境（比如用户目录下的 `.dsh`），
可以把里面的东西搬到 PCL 的实例里。**会先探测，再让你选范围**：

- **仅配置**：只搬插件 + API Key，新环境干净
- **全量导入**：连聊天记录、任务看板、审批白名单、外观偏好一起搬

> ⚠️ 注意两件事：
> 1. 这里**不搬 dsh 版本** —— 版本由「运行时」决定。
>    想连版本一起搬，用 **下载 → 镜像版本 → 运行时** 里的「导入运行时…」
> 2. 会话记录里存的是**工作区绝对路径**，换机器后可能失效，旧会话有可能打不开

---

### 对话历史（设置 → 启动 → 维护与修复）
每个实例的对话历史是**互相独立**的 —— 这正是多实例的意义（换 API Key、换插件组合时互不干扰）。

想把散在各处的对话集中起来时：选一个实例当**来源**，勾选要复制到的**目标实例**，
点「复制对话历史」。

复制是**只补缺**：只把来源实例有、目标实例没有的会话搬过去，
**目标实例已有的会话一个都不会被改动** —— 所以不会丢东西，也不需要先备份。

> 例：实例1 有 `{1,2,3,4}`，实例2 有 `{4,5,6,7}`，用实例1 复制到实例2 →
> 结果是 `{1,2,3,4,5,6,7}`，实例2 原有的 4/5/6/7 原样保留。

## 四、几个容易困惑的点

**「刷新插件列表」要点一下才会出东西**
插件社区不会自动联网（避免每次切页面都卡一下）。想看到列表就点一次
「刷新插件列表」；如果只是想看上次的结果，点「仅读缓存」更快、且不发任何请求。

**第一次启动 dsh 比较慢**
要等 dsh 把服务拉起来（通常几秒到十几秒）。界面右上角有状态显示。

**迁移数据目录之后**
PCL 会自动改用新位置，不用手动改任何设置。想搬回默认位置，
用「维护与修复」里的 **恢复到默认位置**。

**关掉窗口后 dsh 还在跑？**
正常关闭（点右上角 ×）会自动停掉服务。如果是**强制结束进程**，
可能会留下一个后台服务，下次启动程序时会自动回收。

## 五、如果出问题

1. 先看 **顶部「日志」** 页 —— 大部分错误信息都在里面
2. 点 **AI 分析日志**，让它告诉你问题在哪
3. 再看 **设置 → 启动 → 维护与修复** → 点 **检查环境**，
   多数问题点 **一键修复** 就能解决
4. 实在不行，用 **快照** 回到之前正常的状态

反馈问题时，把日志页的内容一起发过来最快。
